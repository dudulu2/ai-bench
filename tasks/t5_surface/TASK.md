# T5 · 连续几何建模（曲面 / 形态发生）

> 与 T4 的区别：本题考察**连续曲面下的形态学正确性与网格质量** —— 拓扑是否干净、
> 有机形态是否符合真实的生长规律、比例与材质是否可信。不是考察布局。

## 任务

用 **程序化生成的连续曲面**（不是体素、不是方块拼装）生成一株**可辨识的真实植物**，
用 Three.js 在浏览器中打开即可观看。

本次参数（由 `gen.py --seed 1` 生成，见 `instance/seed-001.json`）：

- 物种：**银莲花（Anemone）形态的草本开花植物**
- 主茎高度：**90–110 单位**
- 叶片数：**13**
- 开花：**1 朵，6 枚花被片**
- 叶序：**互生螺旋叶序**

## 形态学要求（这是本题的核心，会被量化校验）

1. **叶序**：叶片沿主茎按螺旋互生排列。相邻两枚叶原基之间的**发散角必须接近黄金角 137.5°**
   （允许 ±8° 的生物学波动，但必须围绕这个值抖动，不能是固定 137.5° 的机械重复，也不能是随意角度）。
2. **叶序螺旋**：从俯视能检出清晰的螺旋线（genetic spiral），不得是二列或对生。
3. **形态梯度**：叶柄与叶片尺寸沿茎由下至上呈连续渐变（下部大、上部小），不得突变。
4. **主茎**：有自然的锥度与轻微弯曲（不得是笔直圆柱）；节间长度由下至上递减。
5. **花**：6 枚花被片绕花托均匀排布，有花心（雄蕊群）与花梗；花被片有弧度，不是平面片。
6. **叶脉**：叶片上可见主脉与侧脉（几何或材质均可）。

## 网格质量要求

- 使用连续曲面：`LatheGeometry` / `ExtrudeGeometry` / 参数化 `BufferGeometry` / 细分曲面均可。
- **拓扑必须干净**：无非流形边、无退化三角形、无翻转法线、无自穿透。
- 有合理的法线与材质；不得出现大面积黑面。
- 三角面数控制在 **20 000 – 200 000** 之间（低于则不够精细，高于则判性能扣分）。
- 帧率 ≥ 30fps。

## 交付物

1. 可直接打开的项目（`index.html` 入口）。
2. **`model.obj`** —— 导出整个植物的网格（Wavefront OBJ，纯几何即可，材质可省略）。
   判分机会**解析这个文件重新计算拓扑统计**，与你的 manifest 对账。
3. **`surface-manifest.json`** —— Schema：

```json
{
  "seed": 1,
  "species": "anemone",
  "phyllotaxis": {
    "divergence_angle_deg": 137.5,
    "angle_series": [137.5, 137.1, 138.0],
    "handedness": "clockwise"
  },
  "morphology": {
    "stem_height": 98.4,
    "leaf_count": 13,
    "internode_lengths": [12.1, 11.4, 10.2],
    "petal_count": 6
  },
  "mesh": {
    "triangles": 84000,
    "vertices": 43000,
    "non_manifold_edges": 0,
    "degenerate_triangles": 0,
    "flipped_normals_ratio": 0.0
  },
  "bbox": [42.0, 98.4, 42.0]
}
```

`angle_series` 是相邻叶原基发散角的实测序列，长度应等于 `leaf_count - 1`。
`internode_lengths` 是节间长度序列，长度应等于 `leaf_count`。

4. 判分机会抓取四个机位截图（正面 / 侧面 / 三分之四视角 / 花的特写）用于人工审美评分。

## 判分说明

- **机器判（50 分）**：构建与运行、**拓扑与形态学断言（25 分，本题重点）**、性能、参数复现。
  形态学断言包括：发散角是否围绕黄金角抖动、螺旋是否可检出、形态梯度是否单调、
  以及**从 `model.obj` 重算的拓扑统计是否与 manifest 一致**（不一致 = 虚报，该项归零）。
- **人工判（50 分）**：视觉审美与真实感，由人看渲染图打分。
