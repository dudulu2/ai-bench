// METHOD

判分方式

  • 机器判为主。隐藏测试、契约哈希、几何断言、OBJ 拓扑重算、诱捕题 —— 能确定判的绝不让人判。
  • 人工只在末端出现。每题设自动分门槛，没过门槛的作品直接出分、不进人工队列。人工占比约 32%。
  • 审美与体验用感官分。人工盲评界面一次展示一组渲染图，遮模型名、随机排序，先打分后揭晓。
  • 建模拆成两个方向。体素（离散空间布局）与曲面（连续形态发生）考察内容不同，不合并。
  • v1 直接百分制。六题各 100 分，合计 600。不设归一化基准，待样本 N≥10 后在 v2 引入。
  • 效率只披露不计分。轮次 / token / 耗时作为同分时的参考。
