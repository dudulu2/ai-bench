# T2 · B5 开放式论证质量（15 分）· 人工评分锚点

给 1–10 分感官分，映射为 `分数 = 感官分 / 10 × 15`。

## 看什么

1. **有没有明确表态**：是否给出了结论，而不是"各有利弊"。
2. **论证是否自洽**：前提、推理、结论是否连得上。
3. **有没有识别题面的假设问题**：如果认为"40 分钟回归测试"这个前提本身有问题，直接指出是加分项。
4. **是否回避**：有没有用"视情况而定"来逃避判断。

## 锚点

| 感官分 | 描述 |
|---|---|
| 9–10 | 立场明确、论证严密、指出了题面未言明的假设 |
| 7–8 | 有立场、论证成立，但深度一般 |
| 5–6 | 有立场但论证薄，或论证好但立场含糊 |
| 3–4 | 两边列举，没有结论 |
| 1–2 | 离题或自相矛盾 |
