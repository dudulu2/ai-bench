# T5 · E5 视觉审美与真实感（50 分）· 人工感官评分锚点

给 1–10 分的感官分，映射为 `分数 = 感官分 / 10 × 50`。

## 看什么

1. **像不像一株真的植物**：而不是"参数堆出来的形状"。叶序螺旋是否肉眼可辨。
2. **形态梯度**：下部老叶大、上部新叶小，过渡是否自然连续。
3. **曲面质量**：有无明显的多边形棱角、翻转面、黑面、自穿透。
4. **材质与光影**：花瓣的半透感、叶片的蜡质/哑光区分、叶脉是否可见。
5. **花的完成度**：6 枚花被片排布是否均匀自然，花心是否可信。

## 锚点

| 感官分 | 描述 |
|---|---|
| 9–10 | 照片级可信度或高度风格化的美；叶序、梯度、材质都到位 |
| 7–8 | 明显是这株植物，比例与曲面质量好，但材质或光影略平 |
| 5–6 | 能认出是开花草本，但有明显 CG 感（棱角/塑料感/梯度突兀） |
| 3–4 | 形似而神不似，比例或叶序明显不对 |
| 1–2 | 形态崩坏、拓扑问题肉眼可见 |

## 注意

- 特写机位重点看花的完成度与叶脉。
- 评完再揭晓模型名与机器分。
