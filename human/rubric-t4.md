# T4 · D6 视觉审美与氛围（50 分）· 人工感官评分锚点

给 1–10 分的感官分，映射为 `分数 = 感官分 / 10 × 50`。

## 看什么

1. **整体观感**：第一眼是否成立，是否像一座"中国古典建筑群"而不是一堆方块。
2. **形制可信度**：屋顶曲线、斗拱、开间比例是否经得起看，是否有张冠李戴（如把庑殿顶做成歇山）。
3. **光影与氛围**：黄昏的低角度长投影、暖冷对比是否到位，是否只是"调了个色"。
4. **材质与细节**：红墙/瓦/木构的区分、灯笼石狮等点睛物是否加分而不是减分。
5. **取舍的智慧**：体素分辨率有限时，细节是用在了刀刃上还是均匀铺开。

## 锚点

| 感官分 | 描述 |
|---|---|
| 9–10 | 一眼惊艳；形制准确、光影有戏、细节克制，明显超过"能看"的水平 |
| 7–8 | 完成度高、氛围成立、挑不出硬伤，但缺少让人记住的点 |
| 5–6 | 要素齐全、能认出是中国建筑群，但平淡或某处明显粗糙 |
| 3–4 | 结构基本正确，视觉明显生硬（比例失调/光影缺失/材质糊） |
| 1–2 | 崩坏、看不出是什么，或大量形制错误 |

## 注意

- **只在通过机器门槛的作品里评** —— 没过门槛的不出现在这里。
- 评完一组再揭晓模型名与机器分，避免被数字锚定。
- 三个机位（正面/俯视/三分之四）都看一遍再打分。
