# T3 · C6 工程判断与答复语风（20 分）· 人工评分锚点

给 1–10 分感官分，映射为 `分数 = 感官分 / 10 × 20`。

## 看什么

1. **根因是否说到点上**：一句话能不能说清"真正的根因"，而不是叙述现象。
2. **evidence 是否可信**：有没有真的读到文件的哪一段，而不是泛泛而谈。
3. **有没有读懂系统**：是否发现清单之外的问题、是否指出文档/测试的过时之处。
4. **语风**：像不像一个接手系统的工程师在说话 —— 直接、不谄媚、不写"感谢您的提问"。
5. **敢不敢说 not-a-bug**：把不是问题的现象判定为 not-a-bug 并给出理由，是加分项。

## 锚点

| 感官分 | 描述 |
|---|---|
| 9–10 | 根因精准、证据具体、有额外发现，语风专业 |
| 7–8 | 根因对、有证据，但缺乏额外洞察 |
| 5–6 | 修对了但说不清为什么，或语风啰嗦 |
| 3–4 | 只描述现象，无根因 |
| 1–2 | 答非所问或明显编造 |

## 注意

- 只在自动分 ≥ 60 的作品中评（修都没修对，答复写得好没意义）。
